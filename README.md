# Members-Map Project

## Overview
The Members-Map project is a web application that visualizes member locations on a map using Mapbox. It fetches member data from an API and displays their locations with markers on an interactive map.

## Project Structure
```
members-map
├── src
│   ├── index.html        # Main HTML document
│   ├── css
│   │   └── styles.css    # CSS styles for the project
│   └── js
│       └── app.js        # JavaScript functionality for the project
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies by running:
   ```
   npm install
   ```
4. Open `src/index.html` in your web browser to view the application.

## Usage Guidelines
- The application will automatically fetch member data and display their locations on the map.
- Click on the markers to view more information about each member.
